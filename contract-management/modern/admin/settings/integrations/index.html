    Integrations


    Seamlessly connect CLM365 with third-party applications to enhance functionality and streamline your workflows.


      CLM 365 Mailbox


      Integration feature enabling the synchronization of emails with CLM365. It manages emails related to contracts within the system, centralizing communication for better contract tracking.


      E-Signature


      E-Signature: CLM365 offers integration with leading e-signature platforms, allowing users to digitally sign contracts with ease. Toggle between available services to configure your preferred e-signature provider.


      • DocuSign: Enable the DocuSign toggle to integrate with DocuSign, allowing users to electronically sign contracts directly within CLM365. This integration streamlines the signing process, enhances efficiency, and eliminates the need for manual signatures.


      • Adobe Acrobat Sign: When the Adobe Acrobat Sign toggle is enabled, users can utilize Adobe’s secure digital signature capabilities to sign documents within CLM365, ensuring compliance and a seamless signing workflow.


        • AI Integration


        CLM365 now supports integration with modern AI tools to enhance user experience, streamline workflows, and offer intelligent suggestions.



        • Azure OpenAI Integration: Integration with Azure OpenAI enables advanced language model capabilities within CLM365 for smarter data interaction.

        • Azure OpenAI — Toggle to activate or deactivate AI integration.

        • Azure AI Endpoint — REST API or service endpoint hosted on Microsoft Azure.
        • Azure AI API Key — Authentication token to securely connect with Azure AI services.
        • Azure AI Deployment Name — Identifier of the deployed model within your Azure resource.

          • To learn how to generate and retrieve your Endpoint, API Key, and Deployment Name refer this Guide: Configure Azure AI.

        Once configured, click Save to apply the integration settings.


      • Copilot Integration: Allows enabling or disabling the Copilot assistant feature. To activate, enter the configured Power Automate (PA) URL and click Save. Once activated, Copilot provides intelligent automation and contextual assistance.

        • To integrate Copilot with CLM 365, begin by creating your Copilot agent in Copilot Studio.

        Ensure that you have a Premium Power Automate license to proceed with the configuration.

        In the left-hand sidebar, select Agents.


        If you don’t already have an agent, click on + New Agent to create one, then configure it as required.


        If you already have an existing agent, simply click on that agent to open it.


        In the Knowledge section, add your Knowledge Base.


        Then go to Settings. Under Security, select Web Channel Security and copy the Secret 1 key.




        Next, in Power Automate, go to My Flows and import the Copilot server solution.


        Open the flow and click Edit.


        Disable the New Designer toggle and paste the previously copied Secret 1 value into the Headers field.


        Save the flow and copy the HTTP GET URL generated under the When an HTTP request is received trigger.


        Return to the application, enable the Copilot integration toggle, and paste this URL into the configuration field.


        AI Summary

        The AI Summary feature becomes available once AI Integration is configured with either Azure OpenAI or Copilot. It automatically generates a concise summary of the contract document. For lengthy contracts (100–200+ pages), the AI highlights key elements such as an overview, major sections, critical clauses, risks, compliance factors, actionable insights, and key takeaways — offering a clear and structured understanding of the document.



        AI Agent

        The AI Agent becomes available once AI Integration is configured with either Azure OpenAI or Copilot. It opens a right-side panel that responds to contract-specific queries such as summaries, clauses, timelines, obligations, and risks.

        Unlike general chatbots, it only responds to contract-related queries, ensuring accurate, secure, and context-aware assistance within the selected contract.


        The AI Agent Interface in CLM 365 has been enhanced with a collapsible sidebar feature. This allows users to maximize screen space while still having quick access to AI-powered contract insights. By collapsing or expanding the sidebar, users can choose between a distraction-free view of the contract or instant access to AI guidance.


        Move Icon : Allows users to freely reposition the AI Agent panel anywhere on the screen for convenience.



        Expand/Collapse Icon : Toggles the panel between expanded and collapsed views, letting users choose between a full detailed view or a compact sidebar.


        AI Obligation

        The AI Obligation module simplifies compliance by automatically extracting and managing obligations from uploaded contract documents. Users can attach a contract PDF, and the AI engine identifies and organizes obligations for review and action.

        When creating a contract, upload the contract template in PDF format.


        If AI integration is enabled, click Next to view all obligations automatically fetched from the uploaded PDF.


        The obligations appear in a structured list for easy validation.


        For each obligation, the system auto-fetches the title and description, while you define the category, assign an owner, and set the priority.


        Select whether the task is one-time or recurring.


        If recurring, define the start date, frequency (monthly, quarterly, etc.), and number of occurrences.


        In advanced scheduling, the On option allows you to choose either a specific date (1–31) or select a weekday with its corresponding week number (e.g., 2nd Monday).


        Set the obligation’s end date, either aligned with the contract end date or defined as a custom date.


        When ready, click Add to include the obligation, or deselect it if not required.


        You can deselect any obligation that is not required.


        Publish the contract to finalize and enable obligation tracking.


        All obligations are available in the Obligations section for quick access.


        Clicking on an obligation name opens its detailed view with all associated tasks.

        If the task type is set to one-time, the obligation appears as a single instance.


        If set to recurring, it follows the defined recurrence schedule.


        If you are the obligation owner, open the task to approve or reject it, ensuring accountability and proper compliance tracking.


        AI Clause

        The AI Clause module enhances contract management by allowing users to quickly search, replace, or generate alternative clauses within contract templates. This ensures consistency, accuracy, and flexibility when managing legal language.

        Navigate to Administration, select Contract Type, and choose any contract type template. Click the edit icon to open it.


        The selected contract template opens for editing.


        On the right-side panel, select Search Alternative Clause(s).


        Highlight any text in the template to find alternatives from the existing clause library.


        If AI integration is enabled, click Get from AI to generate intelligent clause suggestions.


        The AI engine provides four alternative options for the selected text, and you can choose the most suitable one.


        After selecting an alternative, click Select to confirm your choice.


        You can replace the clause either within the contract only or in both the contract and the clause library.


        Finally, click Update to apply the changes to the contract template.


        The same option is also available when you open any contract or request. Navigate to the Draft stage and click on the document to edit.


        Within the draft document, you can access the clause replacement and AI-powered suggestions in the same way.



        AI Risk

        The AI Risk feature automatically analyzes contracts and highlights potential risks directly from the document. These risks can be reviewed, modified, or replaced with AI-powered alternatives to strengthen contract compliance and negotiation.

        When you click on Risk in any contract, the system automatically fetches potential risks from the document using AI.



        Click the Edit icon for any risk you want to modify.


        Click the Eye icon next to the clause to view its context.


        The contract template will open, and the selected risk will be highlighted for reference.


        Select Search Alternative Clauses to get AI-generated suggestions.


        AI will provide four alternative options. Choose one and click Update in Content.


        You can either Accept or Reject the changes.


        Only when you accept the changes will the updated text be applied in the contract template.



        How to Integrate Copilot with CLM 365

        Step-by-Step Configuration Guide

        Prerequisites

        The following licenses and subscriptions are required before proceeding with the configuration:

        • Power Automate Premium license
        • Copilot License for the user who is configuring and publishing the Copilot
        • Azure Pay As You Go subscription for Copilot credits

        Part 1: Create the Copilot Agent & Azure App Registration

        These steps cover creating the Copilot agent in Microsoft Copilot Studio and registering the application in Azure.

        Step 1. Enter https://copilotstudio.microsoft.com/ in any browser.


        Step 2. Click on "Agents" in the left navigation panel.


        Step 3. Click on "+ Create blank agent" button at the top right.


        Step 4. Enter the name of the agent (e.g., "CLM 365") and click "Create".


        Step 5. Once the agent is created, click on "Settings" in the top right.


        Step 6. Open https://portal.azure.com/ in a new browser tab.


        Step 7. In the Azure portal, click on "Microsoft Entra ID" in the left navigation panel.


        Step 8. Under Manage, click on "App registrations".


        Step 9. Click on the "+ New registration" button at the top of the App registrations page.


        Step 10. Enter a Name for your application, and then click the "Register" button.


        Step 11. After registration, copy the Application (client) ID from the overview page — you will need this for authentication.


        Step 12. Click on "Add a certificate or secret" link under Client credentials.


        Step 13. On the Certificates & secrets page, click "+ New client secret"./p>


        Step 14. Add a description and choose an expiration period, then click "Add".


        Step 15. Once created, copy the Value of the client secret immediately — it will only be shown once.


        Step 16. Click on "Overview" to return to the application overview page.


        Step 17. Click on "Add a Redirect URI" in the application overview under Redirect URIs.


        Step 18. On the Authentication page, click "+ Add Redirect URI".


        Step 19. Select "Web" as the platform to add the redirect URI.


        Step 20. Enter the Redirect URI for that go back to copilot studio



        Part 2: Configure Security, Authentication & API Permissions

        These steps configure the authentication settings in Copilot Studio and assign all required API permissions in Azure.

        Step 21. Go back to Copilot Studio Settings, click on "Security" in the left panel.


        Step 22. Click on "Authentication" to configure the authentication settings.


        Step 23. Select "Authenticate manually", enable "Require users to sign in", and copy the Redirect URL shown.


        Step 24. Back in Azure, paste the copied Redirect URL into the Redirect URI field and click "Configure".


        Step 25. Now click on "API permissions" in the left navigation panel.


        Step 26. Click "+ Add a permission" on the API permissions page.


        Step 27. In the Request API permissions panel, select "SharePoint".


        Step 28. Select "Application permissions" for SharePoint.


        Step 29. Search for sites under sites, select "Sites.Read.All" and click "Add permissions".


        Step 30. Click "+ Add a permission" again, then select "Microsoft Graph".


        Step 31. Select "Microsoft Graph" from the API list.


        Step 32. Select "Delegated permissions" for Microsoft Graph.


        Step 33. Search for files under Files, select "Files.Read.All" and click "Add permissions".




        Step 34. Click + Add a permission, select Microsoft Graph, choose Delegated permissions, search for openid, select the openid permission, and then click Add permissions.




        Step 35.Click + Add a permission, select Microsoft Graph, choose Delegated permissions, search for profile, select the profile permission, and then click Add permissions.




        Step 36. Click + Add a permission, select Microsoft Graph, choose Delegated permissions, search for Sites, under sites select the Sites.Read.All permission, and then click Add permissions.




        Step 37. Click + Add a permission, select Microsoft Graph, choose Delegated permissions, search for User, select the User.Read and User.Read.All permissions, and then click Add permissions.




        Step 38. Click + Add a permission, select Microsoft Graph, choose Application permissions, search for Files, select the Files.Read.All permission, and then click Add permissions.




        Step 39. Click + Add a permission, select Microsoft Graph, choose Application permissions, search for Sites, select the Sites.Read.All permission, and then click Add permissions.





        Part 3: Grant Admin Consent & Configure Power Automate Flow

        These steps complete the admin consent process in Azure, configure authentication and Web Channel Security in Copilot Studio, and update the Power Automate flow with the required secrets.

        Step 40. After adding all permissions, click "Grant admin consent for bitzap" (or your tenant name) on the API permissions page.


        Step 41. A confirmation dialog will appear. Click "Yes" to grant admin consent for all configured permissions.


        Step 42. Go back to Copilot Studio and open the agent Settings. Click on "Security" in the left panel.


        Step 43. Under Security, click on "Authentication" to configure how users will sign in.


        Step 44.Select "Authenticate manually", then enable "Require users to sign in". Note the Redirect URL shown.


        Step 45.In the Service provider dropdown, select "Microsoft Entra ID V2 with client secrets".


        Step 46. Enter the Client ID (Application (client) ID from Azure) and Client Secret (Value you copied earlier). In the Scopes field, enter : profile openid Files.Read.All Sites.Read.All


        Step 47. Review the Scopes field to confirm it contains "profile openid Files.Read.All Sites.Read.All", then click "Save" to apply.


        Step 48. After saving, click on Security.


        Step 49. Go back to Security settings and click on "Web channel security".


        Step 50. Under Web channel security, copy the "Secret 1" key — you will need this for the Power Automate flow. Then close the page.


        Step 51.Open Power Automate (make.powerautomate.com) and navigate to "Solutions" in the left navigation panel.


        Step 52. In Solutions, click on "HR365 Contract Management Premium" to open the solution.


        Step 53. Inside the solution, click "Objects" in the left panel to browse its components.


        Step 54. Click on "Cloud flows (3)" to view the available flows, then click on "CLM365 Copilot" to open it.


        Step 55.Click the "Edit" button at the top to open the flow editor. Then disable the "New designer" toggle to switch to the classic view.



        Step 56. In the classic flow editor, you will see the flow with "When a HTTP request is received", "Compose", and "Switch" action steps.


        Step 57. Inside the Switch block, click on the "Get Access Token" case to expand and configure it.


        Step 58. Inside the "Get Access Token" case, expand the "Scope" block and click on the "HTTP" action. The HTTP action uses Method: POST and URI: https://directline.botframework.com/v3/directline/tokens/generate.


        Step 59. In the HTTP action Headers field, replace the existing Authorization value with "Bearer " followed by the Secret 1 key you copied from Web channel security in Copilot Studio.


        Step 60. Scroll back to the top of the flow and click on the "When a HTTP request is received" trigger step to expand it.


        Step 61. Copy the "HTTP POST URL" shown in the trigger — this is the endpoint URL that CLM 365 will use to communicate with the Copilot flow.


        Step 62. Click "Save" at the top of the flow editor to save all changes to the CLM365 Copilot flow.


        Step 63. Return to Copilot Studio and click "Publish" at the top right of the CLM 365 agent overview page to publish the final configuration.


        Step 64. Click on Tools in the top navigation of your agent.


        Step 65. Click Add a tool.


        Step 66. Select Connector from the tool type options.


        Step 67. Click SharePoint from the list of connectors.


        Step 68. Select Get items from the SharePoint actions.


        Step 69. Click Add and configure to add the action to your agent.


        Step 70. If needed, update the tool's Name and Description, or leave the defaults as-is.


        Step 71. Select the Site Address for your SharePoint site.


        Step 72. For List Name, change the Fill using option to Custom value.


        Step 73. Choose Enter custom value and type CLM365Contract as the value.


        Step 74. Click Add input to add another parameter to the tool.


        Step 75.Select Top Count from the list of available inputs.


        Step 76. Set Top Count to Custom value and enter 5.


        Step 77. Click Add input again and select Filter Query.


        Step 78. Set Filter Query to Custom value and enter SampleContract ne's.


        Step 79.Click Save to save the tool configuration.


        Step 80. Click Test to open the test panel and try out the agent.


        Step 81. Click Login and copy the sign-in code shown.


        Step 82. Enter the code to complete login — your agent is now ready to use.


        Step 83. Open CLM 365, go to Settings > Integrations > AI Integration. Enable "Copilot AI Integration", paste the HTTP POST URL into the "Copilot URL" field, and click "Save".
