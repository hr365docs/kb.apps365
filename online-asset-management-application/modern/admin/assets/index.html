  • Bulk Update Assets via Excel

      The Bulk Update via Excel feature allows you to update multiple assets at once using an Excel file, helping you save time when making large-scale changes. You can update up to 1,000 assets at a time.

      Step 1: Download the Sample File

      1. Navigate to Add → Bulk Assets.
      2. Select the required Asset Form.
      3. Click Update.
      4. Click Download Sample File to download the Excel template.


      Step 2: Update the Excel File

      1. Open the downloaded Excel file.
      2. Remove the sample data.
      3. Enter the Asset ID of the asset you want to update.
      4. Enter the field and the new value that needs to be updated.
      5. Save the Excel file.



      Note: Updates are performed based on the selected Asset ID or Serial Number.

      Step 3: Upload the File

      1. Return to the Bulk Update Assets panel.
      2. Attach the updated Excel file under Import Files.
      3. Click Upload to process the updates.

      Step 4: Verify the Updates

      1. Locate the asset using the same Asset ID used in the Excel file.
      2. Open or review the asset details.
      3. Verify that the updated values are correctly reflected in the application.

      Important Notes

      • You can update up to 1,000 assets in a single upload.
      • Only the fields provided in the uploaded Excel file will be updated.
      • To make an existing field empty, enter Null in the corresponding Excel cell.
      • To retain the existing value of a field, leave the corresponding cell blank.
      • Ensure that the Asset ID or Serial Number matches the asset you intend to update before uploading the file.

  • Assign Assets

      Here you could assign assets. To add the asset type, follow the below steps:

      1. Click on the Assign Assets from the top navigation panel.



      2. Click on the link under the action column. The panel would be displayed

      3. Enter the Username, select Project, and Return date.


      4. Finally, click on the Assign button.

      5. The assigned asset will be displayed on the Return Assets page.

  • Return Assets

      From here you can able to return assets. To add the asset type, follow the below steps:

      1. Click on the Return Assets from the top navigation panel.


      2. Click on the link under the action column. This would display a panel.


      3. Finally, click on the Return button.

  • Book Assets

    Step 1

    Go to Settings.



    Step 2

    Select 'Advanced Book Assets' from the Features section and enable the toggle. This will display the Book Assets tab on the home page.




    Step 3

    Click on the 'Book Asset' button to book your desired asset.


    Step 4

    Enter and select the 'Booked From' and 'Booked To' dates, then click the Book button.



    Step 5

    In the left navigation bar, click on 'Booking Details' and select the asset.



    Step 6

    In the Booking Details section, all booked details will be displayed. Click the Edit icon to modify details.



    Step 7

    Change the booking status. When changed to 'Booked' or 'Delivered', an email notification is sent to the user.



    Step 8

    Use the Reminder Notification button to send a reminder email to the user.



  • Booking Details

    Step 1

    In the left navigation bar, click on 'Booking Details' and select the asset.



    Step 2

    In the Booking Details section, all booked details will be displayed. Click the Edit icon to modify details.



    Step 3

    Change the booking status. When changed to 'Booked' or 'Delivered', an email notification is sent to the user.



    Step 4

    Use the Reminder Notification button to send a reminder email to the user.



  • Approve/Reject Asset

      Approve/Reject of assets could be done. Click on the Approve and Reject symbol to approve and reject the assets.
