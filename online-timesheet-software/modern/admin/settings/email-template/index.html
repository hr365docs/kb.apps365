    Email Template


    Here you can configure email notification body and add more placeholders.

      User

    • In the "Template Type" dropdown, you can choose the template type.
    • In the "Email Subject" field, you can either change the subject or use the default text.
    • In the "Email Body" field, you can either change the Body or use the default body.


      • Using Placeholders
      • Click on the Placeholder option to view fourteen types of placeholders.




      • Placeholders can be inserted wherever necessary within the email template.
      • Once added, the placeholder values will be dynamically populated and displayed directly in the email.


      This flexibility ensures that email communication remains accurate, consistent, and tailored to each scenario.


      Manager

      The Notification module lets an administrator control every automated email the system sends. All templates live under Settings → Email Template, and are grouped into three categories based on who receives the email: Manager, User, and System. This guide walks through each category, what it's for, and how to configure a template.

      Where to find it

      From the Timesheet Settings screen, open the Email Template section in the left-hand list. Three entries appear: Manager, User, and System. Selecting any one of them opens the list of templates in that category.

      1. Manager Templates
        2.

        Manager templates are the emails sent to a project or reporting manager — for example, reminding them that a timesheet is waiting for their approval. Click Manager under Email Template to open this category.

        • Opening the Manager template
          •



          Settings → Email Template → Manager opens the manager-facing template list.

        • Editing the template and using Placeholders
          •

          Each template has an Email Subject and an Email Body, both of which support rich-text formatting, an Active toggle to enable/disable the email, and an optional Cc list. The Placeholder button inserts dynamic tags (e.g. [WeekNumber], [WeekRange], [Table]) directly into the subject or body — these are replaced with real data when the email is sent.


          The Placeholder panel lists the dynamic tags available for this template, such as Week Number, Week Range, Table, and Approval.

        • Configuring the summary table
          •

          The [Table] placeholder renders a summary grid inside the email. Table configure controls exactly which columns appear in that grid.


          Selecting Table configure opens the Column View panel used to choose the table's columns.


          For the Manager template, available columns include Employee Name, Client:Project, Week No, Email, and Department — tick or untick a column and Save to update the table.

      2. User Templates
        3.

        User templates are the emails sent to the employee themselves — submission confirmations, approval/rejection notices, and pending-timesheet reminders. Click User under Email Template to open this category.

        • Opening the User template list
          •


          Settings → Email Template → User opens the user-facing template list.


          Five user templates are available: Weekly Timesheet Submissions, Daily Timesheet Submission, Timesheet Approved, Timesheet Rejected, and Pending Weekly Timesheet. The Is Active column shows which ones are currently switched on; the pencil icon opens a template for editing.

        • Editing the template and using Placeholders
          •

          As with Manager templates, the subject and body can be edited freely, and Placeholder inserts dynamic tags relevant to the user context — User Name, Project Name, Task Name, Activity Name, Week Range, and Table.


          The Weekly Timesheet Submissions template with its Placeholder panel open, showing the tags available for user emails.

        • Configuring the summary table
          •

          User templates also support Table configure, but the column set is oriented around the employee's own weekly entries rather than manager-level roll-ups.


          Table configure for the User template opens its own Column View panel.


          Available columns include Client:Project, Task, Activity, Task Tracked Hours, each weekday (Mon–Fri), Total, Timesheet Status, and optional fields such as Client Satisfaction Indicator, Learning Activity, and Task Outcome.

      3. System Templates
        4.

        System templates cover administrative and operational notifications not tied to a single manager or employee — project creation/updates, invoices, access requests, missing-approver alerts, delegation changes, and app-update notices. Click System under Email Template to open this category.

        • Opening the System template list


          • Settings → Email Template → System opens the system template list.


          System has the largest set — 11 templates in total, including Project Creation, Project Updation, Invoice Sent, AccessRequest, missing-approver notifications, Weekly Timesheet edited, Request to Assign User Manager, Delegation Removed, and app update emails for users and admins.

        • Editing a System template
          •

          System templates follow the same editing pattern: subject, rich-text body, Cc, an Active toggle, and a Placeholder panel with tags specific to that event (e.g. User Name, Client Name, Project Name for Project Creation). Note that System templates do not expose a Table configure option, since these notifications describe a single event rather than a set of timesheet rows.


          The Project Creation template with its Placeholder panel open, showing the User Name, Client Name, and Project Name tags.

      4. Quick Reference
        5.

        The table below summarizes the three categories at a glance.

        Category Recipient Typical Use
        Manager Project / reporting manager Pending timesheet approval reminders
        User The employee themselves Submission, approval, rejection, and pending reminders
        System Admins / operational events Project changes, invoices, access requests, delegation, app updates

      Common controls across all templates

      • Email Subject / Email Body – the text sent, editable with rich-text formatting (bold, italic, lists, links, images).
      • Placeholder – inserts dynamic tags (e.g. [UserName], [ProjectName]) that are auto-filled with real values at send time.
      • Table configure – (Manager and User templates only) controls which columns appear in the [Table] placeholder's summary grid.
      • Cc – optional additional recipients for the email.
      • Active toggle – turns the notification on or off without deleting the template.

      System

    • In the "System View," you can find additional placeholders.
    • In the "Template Type" dropdown, you can choose the template type.
    • In the "Email Subject" field, you can either change the subject or use the default text.
    • In the "Email Body" field, you can either change the Body or use the default body.
